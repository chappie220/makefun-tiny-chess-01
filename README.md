A compact Python chess engine by chappie220: alpha-beta search with a fixed
24,000-node budget and material + piece-square evaluation.

`main.py` is the packed engine, using Python 3.13 and the standard library.

## Grade locally

With Docker, the makefun CLI, and the unpacked competition kit:

```sh
makefun grade-local --kit /path/to/tiny-chess-01-kit --bot . --driver docker
```
